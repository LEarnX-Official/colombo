# Dr. Giuseppe Colombo — website

A static, quietly luxurious rebuild of drgiuseppecolombo.com. It follows
`../STORYLINE-AND-COMPONENT-DESIGN.md` and uses only the original site's own content.

## Run it

```bash
python3 build.py                          # generates ./dist (96 pages: IT, DE, EN + 404)
python3 -m http.server 8899 -d dist       # open http://127.0.0.1:8899/
```

Requirements: Python 3 with `jinja2` (`pip install -r requirements.txt`).

## Deploy on Cloudflare (GitHub connected)

### Option A — Cloudflare Pages (simplest)
Workers & Pages → Create → **Pages** → Connect to Git → choose this repository, then:

| Setting | Value |
|---|---|
| Framework preset | None |
| Build command | `pip install -r requirements.txt && python3 build.py` |
| Build output directory | `dist` |
| Root directory | *(leave empty — repository root)* |
| Environment variable (optional) | `SITE_URL` = `https://www.drgiuseppecolombo.com` |

Every push to `main` deploys; other branches get preview URLs.

### Option B — Cloudflare Workers (Workers Builds)
Workers & Pages → Create → **Workers** → Import a repository → this repository, then:

| Setting | Value |
|---|---|
| Build command | `pip install -r requirements.txt && python3 build.py` |
| Deploy command | `npx wrangler deploy` (uses `wrangler.jsonc`) |

### Included for Cloudflare
- `dist/_redirects` — 301s from the old WordPress URLs (generated by `build.py`, list in `REDIRECTS`).
- `dist/_headers` — security headers (CSP, HSTS, nosniff…) and long caching for fonts, vendor, CSS/JS
  (CSS/JS URLs carry a `?v=` content hash, so new deploys are picked up immediately).
- `dist/404.html` — served automatically for unknown URLs.
- No external CDNs or Google Fonts: everything is self-hosted.
- The build needs only Python + Jinja2. Journal articles are stored in `data/journal.json`
  (refreshed automatically only when the original `../scraped/` folder is present).

After going live, point the domain in Cloudflare (Custom domains) and remove the old WordPress hosting.

## Structure

| Path | What it is |
|---|---|
| `content_it.py` | **Italian** (primary, served at `/`): the doctor's original texts. |
| `content_de.py` | **German** (`/de/`): translated faithfully from the Italian. |
| `content.py` | **English** (`/en/`) plus shared data (publications, posters, videos). Any key missing in IT/DE falls back to it. |
| `build.py` | Static generator: pages, inline SVG drawings, anatomy and lake illustrations, sitemap. |
| `templates/` | Jinja templates: `home.html` (the 8 scenes), `procedure.html`, `area.html`, `philosophy.html`, `academy.html`, `journal.html`, `article.html`, `contact.html`, `reconstructive.html`, `404.html`. |
| `assets/css/main.css` | Design system (tokens, typography, components, responsive, reduced motion). |
| `assets/js/main.js` | Smooth scroll (Lenis), line drawing, reveals, header, menu, booking panel, page transitions, video and map facades, filters. |
| `assets/js/home.js` | The homepage storyline: scroll-driven scenes 1–8. |
| `assets/vendor/` | GSAP 3.13.0 + ScrollTrigger, Lenis 1.3.4 (self-hosted). |
| `assets/fonts/` | Cormorant Garamond + Inter, self-hosted (no Google Fonts requests). |
| `assets/img/` | Portraits, Atlas covers and course posters (WebP). |
| `data/drawings/` | Dr. Colombo's line drawings, traced to vector paths. |
| `tools/` | The scripts that prepared and traced the drawings (`prep_drawings.py`, `trace.js` with `potrace`). |

## Where the content comes from

- Procedure texts: the original Face, Aesthetic medicine and Breast pages (Italian source).
  The original eyelid section repeated the brow-lift text, so **Eyelid surgery** now uses the
  doctor's own eyelid article.
- Key-facts strips (recovery times, anaesthesia, duration): only where the doctor's own
  articles state them.
- CV, publications, courses: the original CV, the scientific-activity page and the course posters.
- Journal: the 11 original articles, published unchanged in Italian. The duplicate liposuction
  article was merged into one.
